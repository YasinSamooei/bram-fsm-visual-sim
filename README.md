
# 🧠 BRAM Controller FSM – Visual Testbench & Simulation Report

> A cutting-edge VHDL project combining **Finite State Machine (FSM) design** with **Block RAM (BRAM) control**, verified through a **graphical HTML simulation report**.  
> For the first time, testbench results are presented in a **visual, interactive format** inside GitHub.

---

## 🚀 Project Overview
This repository showcases the design, implementation, and verification of a **BRAM Controller based on FSM**.  
The project includes:
- A **BRAM module** (single-port, synchronous memory).
- A **Controller FSM** handling read/write operations with precise timing.
- A **Top-level integration** connecting FSM and BRAM.
- A **Testbench** validating correctness, latency, and signal behavior.
- A **graphical HTML report** that visualizes simulation results.

---

## 📊 Key Features
- ✅ FSM-based control for BRAM read/write operations  
- ✅ 100% test coverage with **all tests passed**  
- ✅ Detailed timing analysis (write latency: 3 cycles, read latency: 4 cycles)  
- ✅ Signal behavior analysis (Busy, CmdValid, DataValid)  
- ✅ Visual timeline of operations across cycles
